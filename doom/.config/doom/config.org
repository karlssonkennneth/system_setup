** Frame placement
Open the frame on the left half of the current monitor. =frame-monitor-workarea=
excludes the menu bar and Dock; the outer/inner difference accounts for the
title bar and borders. Also available as =M-x my/frame-left-half=.
#+begin_src emacs-lisp
(defun my/frame-left-half (&optional frame)
  "Place FRAME (default: selected) on the left half of its monitor."
  (interactive)
  (let ((frame (or frame (selected-frame))))
    (when (display-graphic-p frame)
      (setq frame-resize-pixelwise t)
      (let* ((wa (frame-monitor-workarea frame))
             (x (nth 0 wa)) (y (nth 1 wa))
             (w (/ (nth 2 wa) 2)) (h (nth 3 wa))
             (dw (- (frame-outer-width frame) (frame-inner-width frame)))
             (dh (- (frame-outer-height frame) (frame-inner-height frame))))
        (set-frame-position frame x y)
        (set-frame-size frame (- w dw) (- h dh) t)))))

(add-hook 'window-setup-hook #'my/frame-left-half)
#+end_src

* Keybindings
** Tab switching
The tabs in the top tab bar are managed by =centaur-tabs= and are
automatically organized into groups depending on buffer type:

- A file belonging to a Projectile project is placed in the group
  ="Project: /path/to/project"=.
- A vterm buffer (terminal) has no associated filename, so it falls
  into the default group (e.g. ="General"=) instead of the
  project's group, *even if* you opened it from within that
  project's directory.
- Other special buffers (Magit, Dired, Org, Elisp, etc.) get their
  own dedicated groups regardless of project.

This means you'll typically see at least two groups: one for your
open project files, and another for your terminals.

*** Switching tabs within the same group
- =Cmd+L= (~s-l~) → next tab (e.g. cycle through open files in the
  same project)
- =Cmd+H= (~s-h~) → previous tab

*** Switching between groups (e.g. between projects, or between files and terminals)
- =Cmd+Shift+L= (~s-L~) → next group
- =Cmd+Shift+H= (~s-H~) → previous group

Example: if you have the "myapp" project open with three files, and
a vterm terminal opened from that same directory, =Cmd+L=/=Cmd+H=
will only cycle between the three files. To reach the terminal tab,
use =Cmd+Shift+L= or =Cmd+Shift+H= to jump to the terminal's group,
then =Cmd+L=/=Cmd+H= if you have multiple terminals open in that
group.

*** Opening a new terminal
- =Cmd+T= (~s-t~) → opens a new vterm tab (always creates a new
  instance, never reuses an existing terminal buffer)

*** Loading the tab bar eagerly
Doom enables =centaur-tabs-mode= from =doom-first-file-hook=, i.e. not until the
first *file* is opened. A session spent only in vterm, Magit or an agent shell
therefore never triggers it, and =s-l=/=s-h= do nothing at all -- silently, since
the keys stay bound to autoloaded commands either way.

Enabling it from =doom-after-init-hook= instead means the tab bar is there from
startup. Calling =centaur-tabs-mode= as a hook function enables it (a nil
argument enables rather than toggles outside interactive use), and the command is
autoloaded, so this pulls in the package too. Doom's own hook still runs later
and is harmless: enabling an already-enabled mode is a no-op.

#+begin_src emacs-lisp
(map! "s-l" #'centaur-tabs-forward
      "s-h" #'centaur-tabs-backward
      "s-t" (cmd! (+vterm/here t))
      "s-L" #'centaur-tabs-forward-group
      "s-H" #'centaur-tabs-backward-group)

;; Doom enables centaur-tabs from `doom-first-file-hook', so a session spent
;; only in vterm or Magit never gets a tab bar and the keys above do nothing.
;; Enable it at startup instead; Doom's later call is a harmless no-op.
(add-hook 'doom-after-init-hook #'centaur-tabs-mode)
#+end_src

* Copilot
GitHub Copilot inline completions, powered by the official
=@github/copilot-language-server=. Enabled in all programming
buffers (=prog-mode=).

The first time you use it you need to run these two commands once:
- =M-x copilot-install-server= — downloads the language server binary
- =M-x copilot-login= — authenticates with your GitHub account

#+begin_src emacs-lisp
(use-package! copilot
  :hook (prog-mode . copilot-mode)
  :bind (:map copilot-completion-map
              ("C-<tab>" . copilot-accept-completion)
              ("C-TAB" . copilot-accept-completion)))
#+end_src

* Projectile
** Follow symlinks when indexing
Doom indexes project files with =fd -tl=, which /lists/ symlinks but does not
descend into them. Because the stow-managed configs are symlinks
(=~/.config/doom= → =~/system_setup/doom/.config/doom=), their contents were
missing from ~SPC SPC~ under those paths.

Adding =-L= makes fd follow them. Stowed files then appear twice, once per
path; the noise is small here (~50 extra entries in =~=) because =~/.ignore=
already prunes the large symlinked trees.

The guard matters: =after!= re-runs whenever =config.el= is reloaded (=SPC h r r=),
so an unguarded =concat= would prepend =-L= again on every reload.

#+begin_src emacs-lisp
(after! projectile
  (let ((case-fold-search nil))
    (unless (string-match-p "\\(?:^\\| \\)-L\\(?: \\|$\\)" projectile-git-fd-args)
      (setq projectile-git-fd-args (concat "-L " projectile-git-fd-args)))))
#+end_src

* AI Agents
** agent-shell
[[https://github.com/xenodium/agent-shell][agent-shell]] runs coding agents in an Emacs buffer over ACP (Agent Client
Protocol), so Claude Code, Codex and Gemini all share one interface. The
package is declared in =packages.el=; it needs an external bridge binary:

#+begin_src sh :tangle no
npm install -g @agentclientprotocol/claude-agent-acp
#+end_src

No authentication setup is needed for Claude: =agent-shell-anthropic-authentication=
already defaults to =(agent-shell-anthropic-make-authentication :login t)=, which
reuses the Claude Code subscription login rather than an API key.

Bound under the existing =SPC o l= (llm) prefix, next to the gptel bindings.

Note the explicit =autoload=: =agent-shell= itself is autoloaded by the package,
but the per-agent entry points in =agent-shell-anthropic.el= carry no autoload
cookie, so binding one directly fails with =void-function= until that file is
loaded.

** Per-machine default agent
The work machine uses GitHub Copilot (=copilot --acp=); every other machine uses
Claude Code. =SPC o l c= starts the machine's default agent, and =SPC o l C=
still opens the picker with that agent preselected.

Which machine is which is *not* recorded in this repository. Instead,
=config.el= loads an untracked =local.el= from =doom-user-dir= if it exists, and
that file sets =my/work-machine-p=. Copy =local.el.example= to =local.el= on the
work machine; leave it absent everywhere else. =local.el= is gitignored, so no
machine-identifying details are ever committed.

With Doom workspaces enabled, the tabs module only lists buffers in the current
workspace. =agent-shell= creates its buffer before displaying it, so the usual
buffer-switch hook may not register it. Add it when the shell is initialized
using Doom's existing workspace helper; this also covers new shells started
without switching to them.

Color an =agent-shell= tab red while it has a pending ACP permission request.
Unselected tabs use a stronger red; the selected tab uses a lighter red so its
selected state remains visible. The status is read when Centaur Tabs displays
the tab bar, including when it reuses a cached layout. Agent-shell events
refresh the tab bar when the request appears or is answered.

#+begin_src emacs-lisp
(defvar my/work-machine-p nil
  "Non-nil on the work machine, where GitHub Copilot replaces Claude.
Set this in the untracked `local.el'; see `local.el.example'.")

(defvar my/gptel-copilot-host "api.githubcopilot.com"
  "Copilot API host; override in `local.el' if your plan requires it.")

(defface my/agent-shell-tab-waiting
  '((t (:foreground "white" :background "firebrick" :weight bold)))
  "Face used for unselected agent-shell tabs waiting for a permission response.")

(defface my/agent-shell-tab-waiting-selected
  '((t (:foreground "white" :background "#b65f67" :weight bold)))
  "Face used for the selected agent-shell tab waiting for a permission response.")

(defun my/agent-shell-tab-format-waiting (template)
  "Color tabs in TEMPLATE red when their agent-shell awaits permission."
  (cond
   ((stringp template)
    (let* ((position (text-property-not-all
                      0 (length template) 'centaur-tabs-tab nil template))
           (tab (and position
                     (get-text-property position 'centaur-tabs-tab template)))
           (buffer (and tab (centaur-tabs-tab-value tab))))
      (if (and (buffer-live-p buffer)
               (with-current-buffer buffer
                 (and (derived-mode-p 'agent-shell-mode)
                      (eq (agent-shell-status) 'blocked))))
          (let* ((selected (and tab
                                (centaur-tabs-selected-p
                                 tab (centaur-tabs-tab-tabset tab))))
                 (face (if selected
                           'my/agent-shell-tab-waiting-selected
                         'my/agent-shell-tab-waiting))
                 (copy (copy-sequence template)))
            (put-text-property 0 (length copy) 'face face copy)
            copy)
        template)))
   ((consp template)
    (cons (my/agent-shell-tab-format-waiting (car template))
          (my/agent-shell-tab-format-waiting (cdr template))))
   (t template)))

(defun my/agent-shell-refresh-tabs (event)
  "Refresh tab colors after an agent-shell permission EVENT."
  (when (memq (map-elt event :event) '(permission-request permission-response))
    (when (featurep 'centaur-tabs)
      (centaur-tabs-map-tabsets
       (lambda (tabset)
         (centaur-tabs-set-template tabset nil)))
      (centaur-tabs-display-update))))

(defun my/agent-shell-watch-tab-status ()
  "Refresh Centaur Tabs when this shell receives or answers a permission request."
  (dolist (event '(permission-request permission-response))
    (agent-shell-subscribe-to
     :shell-buffer (current-buffer)
     :event event
     :on-event #'my/agent-shell-refresh-tabs)))

;; Machine-local overrides live in an untracked `local.el' next to this file,
;; so nothing machine-identifying is ever committed. Present only on the work
;; machine; everywhere else the defaults above stand. See `local.el.example'.
(let ((local-config (expand-file-name "local.el" doom-user-dir)))
  (when (file-exists-p local-config)
    (load local-config nil 'nomessage)))

(autoload 'agent-shell-anthropic-start-claude-code "agent-shell-anthropic" nil t)
(autoload 'agent-shell-github-start-copilot "agent-shell-github" nil t)

(setq agent-shell-preferred-agent-config
      (cons 'preselect (if my/work-machine-p 'copilot 'claude-code)))

(after! agent-shell
  (when (modulep! :ui workspaces)
    (add-hook 'agent-shell-mode-hook #'+workspaces-add-current-buffer-h))
  (add-hook 'agent-shell-mode-hook #'my/agent-shell-watch-tab-status))

(with-eval-after-load 'centaur-tabs
  (advice-remove 'centaur-tabs-line-format #'my/agent-shell-tab-format-waiting)
  (advice-add 'centaur-tabs-line :filter-return
              #'my/agent-shell-tab-format-waiting))

(defun my/agent-shell-start-default ()
  "Start this machine's default agent shell (Copilot at work, else Claude)."
  (interactive)
  (if my/work-machine-p
      (agent-shell-github-start-copilot)
    (agent-shell-anthropic-start-claude-code)))

(map! :leader
      (:prefix ("o" . "open")
       (:prefix ("l" . "llm")
        :desc (if my/work-machine-p "Copilot agent shell" "Claude agent shell")
        "c" #'my/agent-shell-start-default
        :desc "Agent shell (choose)" "C" #'agent-shell
        :desc "Open gptel" "l" #'gptel
        :desc "Send to gptel" "s" #'gptel-send)))
#+end_src

** gptel chat
The =:tools llm= module installs gptel. Bind =SPC o l l= explicitly to open a
chat and =SPC o l s= to send a prompt alongside the agent-shell bindings above.
Use the same machine-local switch as
=agent-shell=: GitHub Copilot Chat on the work machine, Anthropic Claude on
the personal machine. The work machine authenticates via =M-x gptel-gh-login=
(or on first request); it does not need an API key. For Copilot Business or
Enterprise, set =my/gptel-copilot-host= in the untracked =local.el= if the
default endpoint is not available for the account.

On the personal machine, gptel's Anthropic backend needs an *Anthropic API
key*, which is separate from the Claude Code subscription login used by
=agent-shell=. Store the key in =~/.authinfo.gpg= using the entry
=machine api.anthropic.com login apikey password YOUR_API_KEY=; never put a key
in this repository.

#+begin_src emacs-lisp
(after! gptel
  (if my/work-machine-p
      (setq gptel-backend (gptel-make-gh-copilot "Copilot"
                            :host my/gptel-copilot-host)
            gptel-model 'gpt-5-mini)
    (setq gptel-backend (gptel-make-anthropic "Claude"
                          :stream t
                          :key #'gptel-api-key-from-auth-source)
          gptel-model 'claude-sonnet-4-5-20250929)))
#+end_src
